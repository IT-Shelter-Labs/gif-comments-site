# GIF Comments website

Static download and support page for GIF Comments 1.0.2.

- Website: https://it-shelter-labs.github.io/gif-comments-site/
- Privacy: https://it-shelter-labs.github.io/gif-comments-site/privacy.html
- Support: melroncode@bk.ru

Deploy with GitHub Pages from main, repository root. No build or JavaScript is required. ZIP downloads include source and GPL notices. Firefox ZIP is for temporary installation; Chromium ZIP is loaded unpacked. Store installation is not claimed until publication is confirmed. Screenshot context is labeled as a demonstration page.
